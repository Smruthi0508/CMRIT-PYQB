## Important Notes

1. **File naming**: Use exact names as shown above in the database inserts
2. **File path format**: Relative paths starting from `question_papers/` directory
3. **Case sensitivity**: Follow the exact case shown (spaces, capitals, etc.)
4. **Other branches** (AIDS, AIML, ISE, CSDS, CSML): Keep their generic subjects as defined in database_setup.sql for semesters 4-7
5. **Professional Electives**: Add as optional subjects if papers are available

---

## SQL Execution Order

1. First: Run `database_setup.sql` to create tables and insert base data
2. Then: Run `insert_4-7sem_papers.sql` to add all question papers
3. Verify: Query the database to ensure all subjects and papers are loaded correctly

**Example verification query:**
```sql
SELECT COUNT(*) as total_papers FROM question_papers WHERE subject_id >= 70;
SELECT DISTINCT s.subject_name FROM subjects s WHERE s.semester_id IN (4,5,6,7) AND s.branch_id IN (6,7);
```
